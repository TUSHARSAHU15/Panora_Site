# Project Setup & Development

This project is built using a modern React-based tech stack.

## Getting Started

To run the project locally, make sure you have Node.js and npm installed.

Clone the repository and install the required dependencies:

```bash
git clone <repository-url>
cd <project-folder>
npm install
npm run dev
```

Once the development server starts, open the local URL displayed in your terminal.

## Tech Stack

The project currently uses:

- **Frontend:** React.js
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Framework:** TanStack Start

## Repository & Updates

The source code is maintained in GitHub. You can work directly with the repository or use Lovable for further development.

Changes pushed to GitHub can also be synced with the connected project.
